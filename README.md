# Sahil Kumar — AI/ML Portfolio

A Next.js 15 + React 19 + TypeScript portfolio with Tailwind CSS v4 and Motion.

## Updated features
- Updated portfolio content from Sahil Kumar's latest resume
- Animated `HI, I AM SAHIL KUMAR` message beside the profile photo
- Animated/hover-responsive profile photo
- Blocky pixel/Minecraft-inspired companion character
- Character eyes follow the cursor
- Character jumps between visible section cards and reacts to hovered cards
- Animated contact form and contact intro
- Next.js loading UI for route/stream buffering states
- 404 not-found page
- Route error page and global error page
- Responsive design and reduced-motion support

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production

```bash
npm run build
npm start
```
